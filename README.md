# Зимний бал — сайт с продажей билетов

Сайт-афиша + оплата через Kaspi + Telegram-бот для организаторов + QR-билеты и проверка на входе.

## Как это работает

1. Гость выбирает билет (1 человек — 1500 тг, 1+1 — 2000 тг) и вводит имя и телефон.
2. Сайт показывает номер Kaspi, сумму и код заявки (`ZB-1234`) для комментария к переводу. Всё копируется в одно касание.
3. Гость переводит деньги и загружает чек (скриншот, фото или PDF).
4. **Чек сразу приходит организаторам в Telegram** с кнопками «✅ Подтвердить» и «❌ Отклонить».
5. После подтверждения на странице гостя **сам** появляется билет с QR-кодом. Если гость нажал «Получить билет в Telegram», бот пришлёт его туда.
6. На входе организатор сканирует QR камерой телефона: открывается билет с зелёной плашкой «БИЛЕТ ДЕЙСТВИТЕЛЕН» и кнопкой «Отметить вход». При повторном скане будет «УЖЕ ПРОШЁЛ».

## Настройка (один раз)

1. **Создайте бота:** напишите @BotFather → `/newbot` → скопируйте токен в `telegram_token` в `config.json`.
   Нужен отдельный бот, а не бот психологической службы.
2. **Узнайте свой Telegram ID:** запустите сайт, напишите боту `/id` и впишите число в `admin_ids` (например, `[123456789, 987654321]`).
   Чтобы чеки приходили в общую группу организаторов, добавьте бота в группу, напишите там `/id` и впишите ответ в `admin_chat_id`.
   Нажимать кнопки могут только люди из `admin_ids`.
3. В `config.json` заполните:
   - `kaspi_phone` и `kaspi_name`: номер Kaspi и имя получателя (как его видит отправитель);
   - `admin_key`: пароль для страницы `/admin` и для проверки на входе;
   - `contact`: Telegram организаторов, например `@dosteam`;
   - `capacity`: лимит гостей (0 — без лимита; пара считается за 2 места);
   - `public_url`: адрес сайта после публикации (нужен для ссылок в Telegram).
4. Установите зависимость и запустите:

```bash
pip install aiohttp
```

```bash
python server.py
```

Или дважды кликните `start.cmd`. Сайт откроется на http://localhost:8080

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Афиша и покупка билета |
| `/t/<код>` | Страница заявки: оплата → чек → билет с QR |
| `/admin` | Организаторам: все заявки, чеки, подтверждение, сумма сбора, отметка входа |

Команды бота: `/stats` (сводка продаж, только для админов) и `/id`.

**Вход на балу:** откройте `/admin` на телефоне и войдите по `admin_key`. После этого любой отсканированный QR покажет кнопку «Отметить вход».

## Публикация в интернет

Чтобы сайт был доступен всем, его нужно разместить на сервере с Python, например на Render, Railway или VPS.
Папку `data/` нужно сохранять: в ней база заявок и чеки. На Render для этого понадобится постоянный диск (Persistent Disk).
Для быстрого теста можно открыть локальный сайт в интернет через `cloudflared tunnel --url http://localhost:8080`.

## Файлы

- `server.py`: сервер, API, Telegram-бот (long polling, вебхук не нужен)
- `static/`: страницы сайта (`index.html`, `ticket.html`, `admin.html`), стили и скрипты
- `data/`: база `orders.sqlite3` и загруженные чеки (создаётся автоматически, в git не попадает)
